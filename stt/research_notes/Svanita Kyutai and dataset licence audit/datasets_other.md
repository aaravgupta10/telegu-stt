# Non-AI4Bharat open speech and text datasets: licence audit and usefulness (Hindi, Telugu, English-India)

Audit date: 2026-10-12. READ ONLY: no dataset files downloaded, no logins, no terms accepted, no forms submitted. Pages, HF API JSON, HF dataset-server metadata, raw READMEs, OpenSLR pages and GitHub raw files were read.
Not legal advice: tiers are engineering risk tiers. Builds on `research_notes/Edge streaming Indic STT pipeline/datasets_licenses.md` (2026-10-08); this file corrects and extends it.

Evidence labels: [M] read on a cited primary page today; [S] secondary source (third-party page or search summary); [E] our arithmetic or estimate; [U] unverified, from memory or not reachable; [OURS] none (no runs).
Tiers: T1 clearly safe / T2 usable with documented caveats / T3 unresolved (do not train until answered in writing) / T4 unusable for a commercial model.

The researcher.md instruction file named in the task did not exist at the given path (Glob found none); I followed the task text and CLAUDE.md rules.

## 0. Executive summary (what changed versus the 2026-10-08 notes)

1. SLR103 (MUCS 2021 sub-task 1 Hindi/Marathi/Odia): the unresolved Microsoft Open Data licence ID `f1f352a6-243f-4905-8e00-389edbca9e83` is titled "Open Use of Data Agreement v1.0" (O-UDA-1.0) per a Law Insider record [S]; the Microsoft host `msropendata-web-api.azurewebsites.net` no longer resolves and `msropendata.com` redirects to a generic Microsoft Research page (Wayback was offline today). The O-UDA-1.0 text itself was read on Microsoft's GitHub [M]: it states "The O-UDA does not impose any restriction with respect to: ... the use or modification of Data; or the use, modification, or distribution of Results", and defines Results to include "Artificial intelligence models trained on Data". So the licence is commercial-friendly if the ID mapping is right. Upgrade SLR103 from T3 to T2 (conditional on written confirmation of the ID mapping and upstream rights). It is 8 kHz story audio, so low priority anyway.
2. MUCS Telugu/Tamil/Gujarati is a different licence ID (`a889b26e-5149-4486-866e-ec896bb728c4`, unresolvable) and the same data is the Microsoft Speech Corpus whose Download Center page says "shall not be used for commercial purposes". Stays T4.
3. NEW and important: RESPIN-S1.0 (IISc SPIRE Lab, NeurIPS 2025 D&B) has large Hindi and Telugu read-speech volumes: paper Table 3 clean slab Hindi 944.93 h and Telugu 1,303.98 h (all slabs: 1,698.6 h and 1,675.5 h). AIKosh lists "Attribution 4.0 International (CC BY- 4.0)"; the GitHub release repo and the paper state no licence. T2. It would change the Telugu-is-the-binding-constraint conclusion in the old Q4 (read, two-domain, dialectal, no English words, so not a conversational replacement).
4. Vaani: hours, CC-BY-4.0 and auto-approve gate confirmed; details in section 2.1. There are also Vaani-transcription-part (updated 2026-10-08), Vaani-Benchmark-V1.0 (Hindi-only, 10.9 h) and third-party copies with no licence tag.
5. Common Voice: latest is Scripted Speech v27.0 (cut-off 2026-09-11, released 2026-09-16), CC0-1.0 on Mozilla Data Collective. The "forbidden usage" clause was found verbatim on each dataset page (section 2.2). Team numbers confirmed. "indian" accent = "India and South Asia (India, Pakistan, Sri Lanka)".
6. DEMAND conflict confirmed exactly: Zenodo metadata licence `cc-by-4.0`, Zenodo description says CC BY-SA 3.0 Unported. Use the more restrictive reading.
7. Aggregator re-uploads on HF routinely relabel licences (examples: `agarwalayushi/hinglish` "CC BY 4.0" over 14 sources including several "See source"; `sorika-labs/vaani-v3-dataset` Apache-2.0 on a compilation, unrelated to IISc Vaani despite the name; `kapturecx/Chaashini` Apache-2.0 over unnamed "publicly available spoken-word material"; `kapturecx/bolAIndia` has no licence tag and its repo holds ~100k `archives/newsonair` manifests, i.e. All India Radio scrapes). Never use these; pull from originators only.

## 2. Detailed findings: Indian datasets

### 2.1 Project Vaani (IISc + ARTPARK, funded by Google)

Primary pages read: HF API `https://huggingface.co/api/datasets/ARTPARK-IISc/Vaani` (lastModified 2026-09-17T10:30:43Z, gated `auto`); the HF dataset page card text; `https://vaani.iisc.ac.in/`; arXiv 2603.28714 (HTML v3).

- Licence [M]: HF YAML `license:cc-by-4.0`. Site: "The data from Project Vaani is available under license : CC-BY-4.0". Paper: "the dataset has been open-sourced via Hugging Face under CC-BY-4.0". The HF card body itself has no licence paragraph and no extra_gated_prompt.
- Gate [M]: "You need to agree to share your contact information to access this dataset ... Log in or Sign Up to review the conditions". `extra_gated_fields`: First Name, Last Name, Country, Company, and "I want to use this dataset for" with options Research / Academic / Commercial / Education. No gate prompt text is exposed by the API (the condition text, if any, is login-only). Gate type `auto` = auto-approved. Commercial is an offered option, which is consistent with the licence.
- Hours [M, card per-language table]: Hindi audio 14,923.7 h / transcribed 1,003.78 h; Telugu 2,326.47 / 184.484; English 336.791 / 22.456. Whole corpus ~31,278 h, 2,122 h transcribed, 165 districts, 105 languages, 156K speakers (card) versus paper 31,255 h / 2,043 h / 158,441 speakers (the paper figure predates the 2026-10-08 update: Vaani-transcription-part card says "total transcribed speech duration has increased from 2048 to 2122 hours"). The old notes' numbers are correct.
- Card inconsistency [M]: says current version includes phase 1 (80 districts) and phase 2 (85 districts) but also "The current version of the dataset that is open-sourced contains is from Phase 1". Size categories disagree between YAML (10M<n<100M) and tags (1M<n<10M).
- Sub-repos by ARTPARK-IISc [M]: `Vaani` (7.21 TB), `Vaani-transcription-part` (244 GB, 86 languages, transcribed only, cc-by-4.0, gated auto, same gate fields), `Vaani-Atypical-Speech-Corpus` (Hindi/Marathi/Telugu, collaboration with Google Project Euphonia; cc-by-4.0), `Vaani-Noise-Event-Dataset` (90,637 segments, ~154.6 h, cc-by-4.0), `Vaani-Benchmark-V1.0` (Hindi test only; ~10.9 h; 5,050 segments; 1,103 speakers; 104 districts; each segment has transcription_v1/v2/v3; "a separate, held-out collection, distinct from the publicly released Vaani dataset"; cc-by-4.0; WER by multi-reference alignment, text normalised by stripping bracketed content).
- Third-party copies [M]: `abar-uwc/vaani-<state>_<district>-cleaned` (~100 repos), `ruchirsahni/Vaani_*`, `nikhatbegum/Vaani-dataset`, `adarshxs/vaani_iisc_dataset` (manual gate) have no licence tag. `sorika-labs/vaani-v3-dataset` is NOT IISc Vaani: its card says Apache-2.0 for "metadata, sharding pipeline, and curation code" and "Individual audio samples retain their respective source dataset licenses (CC-BY-4.0, OpenSLR, etc.)"; sources include Kathbath and FLEURS. Treat every non-ARTPARK copy as T3.
- Provenance and consent [M, paper]: vendor-run mobile app collection; speakers aged 20-70, >= 800 speakers per district, max 15 min per speaker; pincode residence verified with identity documents; consent forms checked in QC; "Send Welcome Kit with Legal Document, Acceptance of T&C". Dual-use risk acknowledged with "speaker ID anonymization, removal of personally identifiable information".
- Audio [M, paper QC]: 16 kHz, mono, 16-bit WAV (Level-2 validation); phone recordings from a mobile app; image-prompted spontaneous speech, 10-20 s effective speech per image. Metadata incl. phone brand/model, age, education, SES.
- Transcript conventions [M, paper Appendix E, card examples, Benchmark card]: native scripts; verbatim; numbers as words; tags [unintelligible], [inaudible], <UNKNOWN_SEGMENT>, <PAUSE> (> 0.5 s), `--` for incomplete utterances, {…} after a misspoken word for the correction; segment invalid if > 25% marked words. English words inside Hindi/Telugu: transcribed in native script followed by the English original in braces. Examples seen: Hindi "एक ट्रक {truck} भी हमे दिख रही है" and Kannada site sample "ಆಪಿಸ್‌{office} ... ರೇಷನ್‌{ration} ಕಾರ್ಡ್‌{card}". Benchmark card: "{EnglishWord}: Code-switched word - Hindi followed by romanized original". So per-token Latin is recoverable by taking the brace content; native-only is obtained by deleting braces. Telugu sample from a third-party copy shows stray Latin letters ("bపార్కింగ్"), so noise in labels exists [M, one sample].
- Splits: none on the card. The paper used its own 80/10/10 per-district split "ensuring no speaker overlap" for fine-tuning (593.93 h Hindi, 113.04 h Telugu in the main experiments; 331 h / 69 h in appendix) [M]. We must build our own speaker-disjoint splits.
- Usefulness: best commercial-safe phone-channel spontaneous Hindi/Telugu; Telugu 184 h is small but unique; English 22 h Indian-accent (image descriptions only). Image-description domain, many dialects (Hindi labelled subsets include Bhojpuri/Maithili-heavy districts: the `language` field must be filtered). Streaming relevant: segment-level utterances, short; phone noise is realistic for laptop-mic robustness but domain is narrow.
- Contamination note: Vaani paper evaluates on FLEURS, CV, Kathbath, MUCS, GramVaani, RESPIN [M], so none of those overlap Vaani's audio; speaker/prompt overlap between public Vaani and Vaani-Benchmark-V1.0 is stated to be none by the card ("distinct") but not measured [U].
- Questions to ask vaanicontact@gmail.com (listed on the card): (1) confirm that the gate text (if any) allows commercial model training and redistribution of derived models; (2) confirm phase-2 inclusion; (3) confirm Benchmark speaker disjointness; (4) attribution wording (paper citation arXiv 2603.28714 is requested on the card).

### 2.2 Mozilla Common Voice (Mozilla Data Collective)

Primary pages: `cv-dataset` GitHub (README, CHANGELOG, `cv-corpus-27.0-2026-09-11.json`); MDC org page; MDC dataset pages for Hindi (`cmu5vlext009to107ev1s9lk8`), Telugu (`cmu617jv900jfo107hpm9aj8d`), English (`cmu5jplf300nwmh07iqvk9leo`) and Spontaneous English (`cmu5nqn1h00vwmi07b4dbk085`); MDC Terms of Service dated May 06, 2026.

- Version [M]: Scripted Speech v27.0, "Clip cut-off date: 11 September 2026", "Date released: 16 September 2026", 42,593 total h / 29,295 validated h, 295 languages. Spontaneous Speech v5.0 (80 languages). Code Switching: "Alpha ... --" no releases. HF `mozilla-foundation/common_voice_*` last modified 2025-10-24 (no licence tag); distribution is via MDC only. HF mirrors (e.g. `fsicoli/common_voice_22_0`) carry cc0-1.0 tags but are re-hosts; MDC forbids re-hosting (below), so prefer MDC.
- Licence [M]: each MDC page: "Licensing: Creative Commons Zero v1.0 Universal (CC0-1.0)"; "Restrictions/Special Constraints: None provided."; "Forbidden Usage: It is forbidden to attempt to determine the identity of speakers in the Common Voice datasets. It is forbidden to re-host or re-share this dataset." Intended use: "training and evaluating automatic speech recognition (ASR) models". Spontaneous Speech README: "All audio contributions are released under the CC-0 license".
- MDC Terms (2026-05-06) [M] relevant to us: "Your rights to use any Dataset are solely as granted in that Data Consumer License"; Appendix 1: "shall not ... scrape, mirror, or redistribute the Dataset"; and "Synthetic Dataset and Model Outputs. Data Consumer shall ensure that any synthetic data, derivative datasets, or model outputs generated using the Dataset (a) do not contain personal data, copyrighted material without authorization, harmful or unlawful speech, or other prohibited content, and (b) are clearly disclosed to downstream users as machine-generated." This last clause matters if we use CV for TTS/pseudo-labelling or voice conversion; its reach over model weights is unclear (no legal advice; ask Mozilla). There is no separate "no re-identification" clause in the MDC ToS body; the clause lives in each dataset's "Forbidden Usage" field.
- Numbers [M, v27 JSON and datasheets]:
  - Hindi: 19,061 clips, 26.74 h, 15.71 h validated, 485 speakers, avg 5.051 s; buckets validated 11,203 / invalidated 981 / other 6,877; splits train 4,899 / dev 2,822 / test 3,402; sentences 32,206 validated + 9,964 unvalidated, 99.5% from sentence-collector (samples look like news headlines, so text provenance is crowd-submitted "CC0" text of news origin [U]); only 15.6% of clips carry an accent field (blank code).
  - Telugu: 2,682 clips, 3.2 h, 0.94 h validated, 75 speakers; buckets validated 793 / invalidated 234 / other 1,655; splits train 100 / dev 98 / test 98; validated sentences only 372 (20,072 total), 30.1% from te.wikisource.
  - English: 2,591,456 clips, 3,795.9 h, 2,826.8 h validated, 100,546 speakers, avg 5.273 s; sentences 92.9% `wiki`; accent counts: us 574,821; england 204,881; other 201,005; indian 153,048 (5.9% of clips, 3,045 speakers, defined "India and South Asia (India, Pakistan, Sri Lanka)"); the 17 accent buckets sum to 1,494,825 of 2,591,456 clips so ~42% of clips have no accent field. Splits: train 1,147,829 / dev 16,403 / test 16,403 clips.
  - Indian-accent hours [E]: 153,048 x 5.273 s = ~224 h (all clips, validated or not); if validated share is like the whole (1,929,854/2,591,456 = 74.5%) then ~167 h. Gender/age self-declared only for a subset.
  - Spontaneous 5.0 English: 5,898 clips, 18.6 h (8.39 validated), 642 speakers, transcripts include disfluencies ("Uh, ..."); no Hindi/Telugu spontaneous release.
- Usefulness: read speech, MP3, clean-ish crowd mics; English accent-weighted subset is the only large CC0 Indian-accent English source (but labelled by self-report, includes Pakistan and Sri Lanka). Hindi/Telugu volumes too small and too few speakers (485 / 75) for training beyond tiny additions; use test splits for eval only if not training on the same sentences.
- Questions for Mozilla (mozilla data collective contact): does the "model outputs ... clearly disclosed as machine-generated" clause apply to ASR model weights/transcripts; confirm CC0 status of crowd-submitted news-derived Hindi sentences.

### 2.3 Google FLEURS (google/fleurs)

- Licence [M]: HF YAML `license: - cc-by-4.0`; card body: "All datasets are licensed under the [Creative Commons license (CC-BY)]". Not gated. lastModified 2026-05-15.
- Hours [E, HF datasets-server `statistics` mean audio duration x num_examples]: hi_in train 2,120 ex 6.66 h, validation 239 ex 0.71 h, test 418 ex 1.34 h = 8.71 h; te_in 2,302 / 311 / 472 ex = 7.92 + 0.89 + 1.45 = 10.26 h; en_us 2,602 / 394 / 647 ex = 7.49 + 1.05 + 1.77 = 10.31 h. Train figures agree with Vistaar's 7 h / 8 h. Paper abstract: about 12 hours per language; speaker column "#S" in the paper language table: Hindi 320, Telugu 82, English 550 (column meaning assumed speakers).
- Provenance [M]: sentences are FLoRes-101 dev/devtest (English Wikipedia sentences, human-translated); FLORES-200 README: "FLORES-200: CC-BY-SA 4.0". So the speech is CC-BY but the transcript text derives from CC-BY-SA text. Because we use FLEURS as eval, this is low risk; do not train on it.
- Role: eval only (read speech, clean). Contamination warning: FLEURS/CV are commonly in public teacher/baseline training sets (NVIDIA, Whisper-family); not verified in this pass [U], so treat FLEURS WER of third-party baselines as optimistic.

### 2.4 RESPIN-S1.0 (IISc SPIRE Lab; NEW)

Sources read: AIKosh page `iisc_respin_s1_0_corpus.html`; NeurIPS 2025 D&B paper PDF (papers.nips.cc); GitHub `saurabhk0317/respin_data_neurips25` README and file list (no LICENSE file); SPIRE page (JS-only, form-gated content not visible); HF third-party test-only copy `rimrafadii/respin-iisc` (cc-by-4.0 YAML, test splits only).

- Licence [M]: AIKosh: "License Attribution 4.0 International (CC BY- 4.0)", uploaded by Prasanta Kumar Ghosh 18/06/25, "Visibility Open". The GitHub README and the paper do not state a licence (paper checklist item "Licenses for existing assets: Yes" is not a licence statement). Hosting: direct links to an E2E Networks object store (e2enetworks) listed in the GitHub README; no gate visible there. The SPIRE site apparently uses a form for access [S]. Funded by the Gates Foundation; ethics clearance at IISc; "informed consent for the public release of their anonymized data" [M, checklist].
- Content [M]: nine languages (bn, bh, ch, hi, kn, mg, mr, mt, te); read speech of sentences composed by dialect experts in agriculture and finance domains; ~203,536 unique text IDs; recorded through a crowdsourced mobile "Bolo App"; 16 kHz, 16-bit, mono WAV; avg 5.35 s; total 12,652 h per the repo (paper: "over 12,000 hours"; AIKosh: "over 10,000 hours of validated audio"). Slabs Clean / Semi-noisy / Noisy by transcription quality; dev and test manually verified.
- Per-language hours [M]: Paper Table 3 totals: Hindi clean 944.93 / semi-noisy 362.79 / noisy 390.86 (sum 1,698.6); Telugu clean 1,303.98 / 222.53 / 148.99 (sum 1,675.5). Use the repo numbers for planning.
- Speakers: Hindi 2,305 speakers in train_hi_clean; Telugu 2,287 (repo table); dialects Hindi D1-D5 (Muzaffarnagar, Etah, Hamirpur, Nagaur, Tehri Garhwal), Telugu D1-D4 (Guntur/Krishna, Chittoor/Anantapur, Karimnagar/Nalgonda, Srikakulam/Visakhapatnam).
- Transcript conventions [M, paper appendix text-normalisation table]: native script; "English Words []" in the allowed-token table, i.e. English words were removed or transliterated in the text; digits expanded. So RESPIN provides no Latin-script English words and no code-switch.
- Usefulness: Telugu is the language where open commercial-safe volume is scarcest, and RESPIN adds ~1.0-1.3k h of clean read speech from ~2.3k speakers across four dialect regions. Weaknesses: only agriculture/finance sentence pool (~20k sentences per language, so heavy text repetition across speakers: 19,978 sentences in train_te_clean for 702,883 utterances), read style, mobile crowd mic. Good for acoustic/dialect robustness and CTC/Transducer pretraining stage; must be balanced against IndicVoices/Vaani-like spontaneous data to avoid a read-speech bias.

## 8. Overlap and contamination notes

- Vaani paper evaluation sets: GramVaani, FLEURS, MUCS, Common Voice, Kathbath(-Noisy), VAANI, RESPIN [M]; so those are the community's de facto Hindi/Telugu benchmarks and none overlap Vaani audio.
- FLEURS text is FLoRes (Wikipedia) and CV English text is 92.9% Wikipedia: wiki-derived LM text overlaps both eval sets' sentences.
- RESPIN Hindi/Telugu text pool is shared across thousands of speakers; speaker-disjoint but not text-disjoint between train and test unless the official dev/test splits are used (they are speaker- and text-curated per paper F.3).
- agarwalayushi/hinglish and sorika-labs copies re-pack Kathbath, FLEURS, CV: any model trained on them is contaminated with eval sets.
- NVIDIA/other public teachers trained on FLEURS/CV: not verified here [U].
